## Como instalar no Android

1. No celular, toque no link de download acima para baixar o arquivo `cclass-app-1.0.1.apk`.
2. Ao concluir o download, toque no arquivo na barra de notificações ou na pasta **Downloads**.
3. Se o Android solicitar permissão, habilite **"Permitir desta fonte"** para o navegador ou gerenciador de arquivos.
4. Toque em **Instalar** e aguarde a conclusão.

### Como atualizar para uma nova versão

- Não é necessário desinstalar a versão anterior.
- Ao abrir o aplicativo, quando houver uma atualização disponível, um aviso será exibido na tela com o botão **Baixar atualização**.
- Basta baixar e instalar por cima da versão atual — sua conta e preferências serão preservadas.

---

## Requisitos mínimos

- **Sistema:** Android 8.0 (Oreo) ou superior
- **Conexão com a internet:** necessária para login, pareamento por QR Code, sincronização de histórico e consultas/simulações na Calculadora RTC
- **Câmera (opcional):** utilizada apenas para leitura do QR Code de pareamento com o painel web (`cclass.app.br`)

---

## Acesso rápido por QR Code

1. Acesse o painel web do **cClass.app** no navegador e faça login.
2. Abra a opção **Conectar Aplicativo Mobile** no menu.
3. No aplicativo Android, toque em **Escanear QR Code** na tela de login e aponte a câmera para a tela do computador.
